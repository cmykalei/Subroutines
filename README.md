# Subroutines
COMPX203 Exercise 2: subroutine implementations in C and assembly.

## Project 🌳
```
.
├── ex2_q1.c
├── ex2_q2.s
└── ex2_q3.s
```

### Usage
Compile on the lab machines using the course build environment:
```bash
gcc -o ex2_q1 ex2_q1.c
```

## Commands
1. To compile the C exercise use `gcc -o ex2_q1 ex2_q1.c`.
2. To assemble an exercise use the course assembler on `ex2_q<n>.s`.
